# GAZETA STUDIO

Web oficial de **Gazeta Studio** — lienzos y arte de autor en edición limitada.

- **Autor y director:** Juan Casper
- **Paleta:** blanco (base principal), negro y color vino
- **Inspiración:** tienda minimalista tipo Desenio

## Titulares

- **Inicio:** «Arte exclusivo con estilo propio»
- **Colecciones:** «Las segundas partes nunca funcionan»
- **Manifiesto:** «El arte habla solo si sabes escuchar»

## Filosofía de la casa

1. **Ediciones exclusivas y limitadas** — tiradas cerradas anunciadas de antemano.
2. **Tamaño único por obra** — cada obra tiene un tamaño concreto; no se puede elegir la misma obra en varios tamaños. El tamaño forma parte de la obra.
3. **Expertos en gran formato** — especialidad en lienzos de gran tamaño (también hay formatos normales).
4. **Numeración y certificado** — cada lienzo va numerado a mano y con certificado de autenticidad firmado por Juan Casper.
5. **Cierre definitivo** — cuando una colección se cierra, no se puede volver a comprar. Nunca. Sin reediciones.
